# Stránkovanie

## Slovensky

- **Projekty:** zaviesť stránkovanie zoznamu projektov.
- **Úlohy:** použiť nekonečné posúvanie. Ďalšiu dávku načítať cez pointer s ID poslednej načítanej úlohy.
- **Audit log:** použiť bežné stránkovanie.

## Česky

- **Projekty:** zavést stránkování seznamu projektů.
- **Úkoly:** použít nekonečné posouvání. Další dávku načíst pomocí ukazatele s ID posledního načteného úkolu.
- **Audit log:** použít běžné stránkování.
